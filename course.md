# Craft of Computing - Current Course Summary

## Overview

- **Programme:** B.Sc. Information Sciences
- **Credits:** 5 | **Semester:** 3 | **Level:** 1 | **Type:** Core
- **Prerequisites:** None
- **Academic Year:** 2026-27
- **Dev Team:** Anuradha, SriRam (last edited: Jerome)

A breadth-first preparatory course that gives students a bird's-eye view of Information Sciences. Students get snippets of math, tools/technology, computer internals, and the historical/philosophical context of the discipline. The emphasis is on establishing the right relation between human and machine -- understanding what needs to be automated, how to think about problems, and how to dialog with machines using formal languages.

## Pedagogy

- Hands-on (hardware and software)
- Form and content unified -- conceptual ideas dovetailed with lab work
- Problem-based learning with unconventional, fun problems
- Team-based learning (Arduino projects, exploratory group projects)
- Fun sessions with Arduino kits, teamwork, debates, and presentations to overcome beginner intimidation

## Learning Objectives

1. Design and construct simple hardware and software artifacts
2. Reflect on the nuances of a problem and design a solution for it
3. Classify technical content, organize and explain it

## Structure (4 Units, ~14 weeks)

### Unit 1: Crafting Little Machines (3.5 weeks)

Hands-on exploration of "What is a machine?" -- from electricity to electronics to digital.

- Basic electricity and electronics
- Arduino Playground, TinkerCAD simulations
- Small projects with Arduino kits
- Connecting peripherals, assembling a computer
- Basic block organization of a computer

### Unit 2: The Operating System as an Ecosystem (4 weeks)

The OS as the layer over raw machines. Students learn to navigate, structure files, and script shortcuts.

- What is an OS? How is it structured?
- Files and directories
- Bash commands
- Using an editor (vi)
- Basic shell configuration
- Basic administration, access rights, managing users

### Unit 3: A Peek at Programming (4 weeks)

Introduction to programming with emphasis on its "2-timing-ness" (planning and execution). Programming as constructive mathematics instructing a mathematical machine.

- Bash programming / scripting
- Number systems, logic gates
- Introduction to Python (weeks 10-12):
  - Basic computation with lists, tuples
  - Branching, iteration
  - Abstraction, functions

### Unit 4: Introduction to Data-ing (2.5 weeks)

A small slice of the data world -- from spreadsheets to macros to Python tables.

- Using Excel sheets and special functions
- Writing little macros (VBA)
- A sense of AI-powered data-ing

## Assessment

| Component | Count | Weight |
|---|---|---|
| Quizzes (best 4 of 5) | 5 | 40% |
| Take-home assignments | 2 | 10% |
| Group projects | 2 | 40% |
| Class participation | 1 | 10% |

**Quizzes:** electricity/Arduino, vi basics, Linux commands, number systems/logic gates, Python programming.

**Group Projects:** (1) Arduino hardware project (before mid-sem), (2) exploratory project on Excel and Linux (end of semester).

**Participation formula:** Score = 0.2A + 0.4B + 0.3C + 0.1D (A=attendance, B=quality of contributions, C=responsiveness/preparation, D=attitude/conduct).
