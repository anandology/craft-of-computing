# Course files

Everything in this folder is copied into your home directory when you run
`craft.sh update`, one folder per week.

The original copies stay in `~/.craft/content/` and are never edited. If you
change a file and want the original back, copy it from there:

    cp ~/.craft/content/week2/notes.md ~/week2/

Your own work is safe: updates never overwrite a file that already exists in
your home directory.
