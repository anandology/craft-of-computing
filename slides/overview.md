# About the Course

What is this course, who it is for, and what it sets out to achieve.

---

## What is this course?

- The **first course** in the Information Sciences **major and minor**.
- A core, hands-on course that explores different **facets of computing**.
- For students in their **first semester** with limited prior exposure to computing.
- Built around **activities and projects** rather than lectures.
- Goal &mdash; move students from **passive consumers** to **active creators** and **problem solvers**.

---

## Facets of computing

- **Command line** &mdash; become comfortable driving a computer through a command line interface and the Linux shell.
- **Programming** &mdash; use a general-purpose programming language (Python) to build structured tools.
- **Microcontrollers** &mdash; interface a computer with the external world using ESP32 hardware.

---

<!-- _class: lead -->

# Intended Learning Objectives

## Five objectives guide what you will be able to do at the end of the course.

---

## Learning Objectives

- **ILO 1 &middot; Execute** &mdash; carry out computing tasks by following guidelines or consulting manuals.
- **ILO 2 &middot; Collaborate** &mdash; foster an **inclusive**, responsible environment and a culture of sharing and care.
- **ILO 3 &middot; Troubleshoot** &mdash; infer and explain outputs of commands or code; fix failures.
- **ILO 4 &middot; Create** &mdash; apply familiar tasks in creative, thoughtful ways to generate new outcomes.
- **ILO 5 &middot; Reflect** &mdash; introspect on learning and know when and how to seek help.

# Unit 1

## Computing with the Command Line

---

## Unit 1 &middot; Command line (5 weeks)

- Explore **vignettes of computing history**.
- Learn to use a **command line interface**.
- Use course-specific tools to **create and update web pages** with sketches.
- Write **simple shell scripts** to automate and combine manual steps.
- Appreciate the utility of the **Linux shell**.

---

<!-- _class: lead -->

# Unit 2

## Exploring Python

---

## Unit 2 &middot; Python (5.5 weeks)

- Move from the command line to a **general-purpose programming environment**.
- Learn the **basics of structured programming** in Python.
- Build **more complex tools** than in Unit 1.
- Understand what happens **behind the scenes** when tools run.

---

<!-- _class: lead -->

# Unit 3

## Interfacing with Microcontrollers

---

## Unit 3 &middot; Microcontrollers (4.5 weeks)

- Interface your computer to the **external world**.
- Use **ESP32 microcontrollers** programmed with **MicroPython**.
- Work with **sensors and output devices**.
- Realize that computation **need not always be abstract**.

# Assessments

## A balanced set of assessments map to the intended learning objectives.

---

## Assessment breakdown

| Assessment | Count | Weight (each) | Overall |
|------------|------:|:-------------:|:-------:|
| In-class Reflections | 2 | 4% + 7% | 11% |
| Group Presentation | 1 | 5% | 5% |
| Group Projects | 3 | 5 + 10 + 10% | 25% |
| Activity Reports | best 3 | 3% | 9% |
| Test | 1 | 20% | 20% |
| Learning Journal | 1 | 20% | 20% |
| Class Participation | 1 | 10% | 10% |

---

## What each assessment looks like

- **In-class Reflections** &mdash; write at start (wk 2) and end (wk 14) about views of computing.
- **Group Presentation** &mdash; explore a vignette of computing history; an early chance to know classmates.
- **Group Projects** &mdash; open-ended project per unit (groups of 3-4).
- **Activity Reports** &mdash; brief report each session, best three submitted.
- **Test** &mdash; in-class, predict outputs of commands / Python code (weeks 11-12).
- **Learning Journal** &mdash; online journal built from Markdown; six minimal entries.
- **Class Participation** &mdash; collaboration, responsible use, active engagement.
