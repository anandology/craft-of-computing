# Setup Instructions

The craft of computing course requrires setting up some software on your laptop.

It is recommened that you install Ubuntu Linux 26.04 on your laptop for this course. If you are used to Windows, you install Ubuntu can setup Ubuntu with dual boot, that will allow you to switch between Ubuntu and Windows at the boot time.

## Linux

Linux comes with most developer tools preinstalled. 

Open a Terminal and run the following command to to install all the software.

```
sudo apt install python3 curl figlet cowsay
```

## Windows

If you are not keen to install Ubuntu directly, you can try instaling Ubuntu inside your Windows installation using Windows Subsystem for Linux (WSL). 

Please follow the instructions in [Installing Ubuntu on Windows using WSL](ubuntu-wsl.md)
